# Homework 1 – Proteomic and Metabolomic Characterization of COVID-19 Patient Sera

This repository contains the solution for Homework 1 of the DMI course (Lectures 1–3).

## Contents

* R Markdown analysis (`.Rmd`)
* Reproduction of Table 1 and Supplementary Figure 1
* Exploratory Data Analysis (EDA)
* Outlier handling and transformation
* Heatmap with hierarchical clustering

## Data

The dataset is automatically downloaded from the original publication:
Shen et al. (2020) – *Proteomic and Metabolomic Characterization of COVID-19 Patient Sera*.

## Methods

* Data cleaning and wrangling with `tidyverse`
* Missing data imputation using `mice`
* Statistical analysis (ANOVA and t-tests for exploratory purposes)
* Visualization with `ggplot2` and `pheatmap`

## Notes

* Table 1 is reproduced as closely as possible based on the available supplementary data and preprocessing steps.
* No observations were removed during the analysis.
